📌 Cách cài đặt (làm 1 lần)

  1. Tạo Google Sheet với 3 tab: SoXe, LaiXe, KhoBoc
  2. Tab SoXe: cột A = Biển số, cột B = Loại xe
  3. Tab LaiXe: cột A = Tên, cột B = SĐT, cột C = CCCD
  4. Tab KhoBoc: cột A = Tên kho (mỗi kho 1 dòng)
  5. Copy Sheet ID từ URL → dán vào ô trên → Lưu → Tải dữ liệu
  6. Nhớ share sheet: Anyone with the link → Viewer
📋 Mẫu dữ liệu tab SoXe:
A1: 29H-77696   B1: Xe tải
A2: 29E-12900   B2: Container

📋 Mẫu dữ liệu tab LaiXe:
A1: Ngô Hoàng Vũ   B1: 0559827827   C1: 079083034316
📤 Apps Script (ghi đơn hàng):
  1. Vào Extensions → Apps Script trong sheet
  2. Dán code → Deploy → Web app → Anyone → Deploy
  3. Copy URL dán vào ô "URL ghi đơn hàng" ở trên
